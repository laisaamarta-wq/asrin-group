# ASRIN GROUP — website redesign (TR / EN / RU)

A static, multilingual site generated by a small Node build script. There is no server code and nothing to maintain beyond the content file.

## Structure

```
src/content.mjs     all copy in Turkish, English and Russian, plus project data (one place to edit text)
src/alts.mjs        image alt texts in three languages
src/templates.mjs   page templates (home, about, projects, project pages, gallery, videos, news, FAQ, contact, 404)
src/styles.css      design system and layout
src/main.js         motion (GSAP + ScrollTrigger + Lenis), menu, lightbox, filters, contact form
src/svg.mjs         vector ASRIN GROUP logo (traced from the original) and icons
media-src/          source images (enhanced + originals); the build makes responsive WebP sizes
media-video/        web-optimised Blue Lagoon films
build.mjs           builds everything into dist/
dist/               the finished site — this folder is what gets deployed
```

## Build

```
npm install
node build.mjs
```

## URLs

- `/tr/…` Turkish (default), `/en/…` English, `/ru/…` Russian, with localised slugs, hreflang, canonical and localised metadata. The `sitemap.xml` lists all language versions.
- `/` sends visitors to their saved or browser language (Turkish by default).
- `dist/vercel.json` permanently redirects the old asringroup.net URLs (`/tr/proje/asrin-city-gazipasa-98` and so on) to the new pages.

## Contact form

The form needs no server: **Send via WhatsApp** opens WhatsApp with the enquiry already written to +90 539 261 39 95, and **Send by email** opens the visitor's mail app addressed to info@asringroup.net. If you later want enquiries to arrive without the visitor's app opening, add a form endpoint (for example a Vercel function with an email service key).

## Imagery

- **Enhanced with AI (Higgsfield · Nano Banana 2.1), using the real photos as references.** The architecture, floors, facades and pools are kept; only the light, sky, colour and camera position were improved: `city-hero`, `city-dusk`, `city-detail`, `city-pool`, `city-topdown`, `city-vertical`, `town15-main`, `villa-main`, `villa-pool`, `a1011-main`, `a78-main`, `gazipasa-coast`.
- **Originals, colour-graded only:** `city-drone-*`, `city-palm`, `city-gate`, `town15-*`, `villas-*`, `a1011-*`, `a78-2`, `gazipasa-01…09`.
- **Blue Lagoon Village:** the images and films come from the Blue Lagoon Village website repository.
- The footer and gallery say that some photographs have been digitally enhanced.

## Content sources

All facts come from asringroup.net and blue-lagoon-village.vercel.app. On the old site, the Team, News, Videos, Planned and Under-construction sections were empty, and the FAQ was placeholder text. On the new site:

- News is a timeline of real milestones.
- Team is a section on the About page, without names.
- The FAQ answers come from published facts.
- The Planned and Under-construction tabs show an honest empty state with a call to action.
